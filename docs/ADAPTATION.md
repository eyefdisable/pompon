# Адаптация под другую компанию

Одна компания — один экземпляр приложения и своя база PostgreSQL.

## Меняется в кабинете, без программиста
| Раздел | Что можно менять |
|---|---|
| Тарифы | названия и цены вариантов, минимальный заказ, % сильных загрязнений, % второй стороны матраса, доплата за выезд за город, шаг округления |
| Компания | название, подзаголовок, акцентный цвет, телефон, Telegram, email, режим работы, город, территория, оператор данных для политики |
| Игра | выключена / без скидки / бонус; сумма, срок и минимум следующей чистки |
| Персонажи | характер (дружелюбный, сдержанный, с юмором), отключение лиц и рук, отключение реплик |
| Доступ | смена пароля (закрывает все сеансы), выход |

Пустые контакты на сайте не показываются: заглушек вроде «+380 00…» нет.

## Нужна правка исходников (обычно 0,5–2 дня разработчика)
- Логотип: `Logo` в `src/server/pages.tsx`. PWA-иконки и картинка для соцсетей: `scripts/icons.mjs`, запуск `node scripts/icons.mjs`.
- Полная палитра, шрифты, отступы: переменные в начале `src/client/styles.css`.
- Тексты главной, «Как это работает», политика: `src/server/pages.tsx`.
- Реплики и новые характеры: `PHRASES` в `src/shared/config.ts`.
- Новые варианты внутри категорий: `DEFAULT_SETTINGS` в `src/shared/config.ts`. Цены потом правятся в кабинете.
- Новые или изменённые 3D-модели: функции в `scripts/build-models.ts`, затем `npm run models`. Можно положить GLB из Blender с теми же именами узлов (`fabric`, `frame`, `face`, `eyeL/eyeR`, `pupilL/pupilR`, `armL/armR`, `anchor`). Обивка — один меш с UV без перекрытий, иначе игра с пятнами работать не будет.

## Оценивается отдельно (новая функциональность)
- Новые категории услуг (не варианты внутри существующих).
- Онлайн-оплата: эквайринг, договор с банком, фискализация.
- Расписание мастеров и слоты, несколько ролей и сотрудников.
- Интеграции с CRM и телефонией.
- Уведомления о новых заявках в Telegram, SMS или email. Сейчас кабинет обновляет список сам каждые 45 секунд, push-уведомлений нет.
- Автоматическое погашение бонусов и античит.
- Мультиязычность, несколько городов с разными прайсами.

## Регулярные расходы покупателя
- Хостинг Node.js: VPS от ~5 $/мес или PaaS.
- PostgreSQL: на том же VPS или управляемый, от ~0–15 $/мес. Фото занимают ~100–300 КБ на штуку.
- Домен и HTTPS: сертификат Let's Encrypt бесплатный.
- Платных API и нейросетей нет: стоимость не растёт от числа визитов.

## Перед запуском
1. Заполнить «Компания» (контакты, оператор данных) и «Тарифы».
2. Проверить с юристом текст политики конфиденциальности (`/privacy`).
3. Задать уникальный `APP_SECRET`, сменить стартовый пароль в «Доступе».
4. Настроить резервное копирование базы (`pg_dump` по расписанию или бэкапы провайдера).
