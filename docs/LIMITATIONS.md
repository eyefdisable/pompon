# Ограничения и что осталось сделать

## Отклонения от исходного ТЗ (из-за среды разработки)
В среде сборки не было доступа к npm, Figma и Blender. Поэтому:

| В ТЗ | Сделано | Как довести |
|---|---|---|
| Next.js | Node `http` + React SSR + esbuild. Публичные страницы рендерятся на сервере, есть метаданные, sitemap и robots | Перенос на Next.js App Router: страницы из `pages.tsx` → `app/`, API → Route Handlers. Логика в `src/shared` и `src/server` переиспользуется |
| Three.js + React Three Fiber + Drei | Собственный WebGL2-движок (~500 строк): GLB, тень, орбита, raycast, UV-маска | Заменить `src/client/three/engine.ts` компонентом R3F (`useGLTF`, `OrbitControls`, `ContactShadows`). Модели и имена узлов совместимы |
| Motion | Анимации на CSS и в движке, с учётом reduced motion | Подключить `motion` для переходов интерфейса |
| Драйвер `pg` | Собственный клиент протокола PostgreSQL v3 (SCRAM, TLS, пул, транзакции) | Заменить на `pg`, интерфейс `query/tx` совместим по смыслу |
| Бесплатные модели (CC0 и т.п.) | Свои процедурные модели: права полностью ваши, атрибуция не нужна | При желании взять CC0-модели (например, Poly Haven), положить их в `LICENSES.md` и привести к именам узлов из ADAPTATION.md |
| Доработка в Blender, `.blend` | Нет: Blender недоступен. Модели в GLB открываются в Blender (File → Import → glTF) | Импортировать GLB, доработать, экспортировать с теми же именами узлов |
| Figma-файл с экранами | Нет: Figma недоступна. Вместо него скриншоты основных экранов и состояний в `docs/screens/` | Сделать макет в Figma по скриншотам |
| `@types/react`, `npm run typecheck` | Типы проверены с минимальной заглушкой (`tsconfig.offline.json`) | После `npm install` выполнить `npm run typecheck`: могут всплыть мелкие замечания строгих типов React |
| `package-lock.json` | Не создан (нет сети) | Появится при первом `npm install` |

## Что не проверено
- Работа на реальном телефоне. Проверены только мобильная ширина 390 px с эмуляцией касаний и программный WebGL (SwiftShader) в Chrome 153 в контейнере.
- Safari и Firefox.
- Установка PWA и офлайн-экран на HTTPS-домене. Сервис-воркер собран и регистрируется, но в прогоне был заблокирован, чтобы проверять сетевые сбои.
- Публикация на хостинге: развёртывание не выполнялось, нужны ваши хостинг и база.
- `npm install` с указанными версиями: пакеты взяты из предустановленной копии тех же версий.

## Известные ограничения MVP
- Бонус за игру применяется вручную (кнопка «Отметить погашенным»). Защищённого античита нет: сервер проверяет только правдоподобность длительности игры.
- Уведомлений о новых заявках нет: кабинет обновляет список каждые 45 секунд и по кнопке.
- Один владелец, без ролей.
- Если после неудачной отправки клиент изменил форму, повтор уйдёт новой заявкой. Если первая попытка всё же дошла до сервера, будет две заявки, владелец увидит обе.
- Загруженные, но не отправленные фото удаляются через сутки. После перезагрузки страницы черновик хранит только их превью.
- Размер и вариант (2 места, угловой, двуспальный) меняют цену, но не 3D-модель. Это подписано под сценой.
- Наклон камеры мышью работает, на телефоне вертикальный жест прокручивает страницу. Масштаб — щипком, мышью — Ctrl+колесо.
